## 重新构建

```bash
pip install python-pptx pillow
python polish/build.py        # 输出到 dist/
```

- `polish/theme.py` —— 配色、字号、栅格与页面组件（卡片、数据卡、结论条、芯片、图片定位与裁切）
- `polish/build.py` —— 24 页版式

图片放置规则：含数据的图（图表、表格、流程图、色谱图、检测报告）走 `pic_fit()` 等比缩放**不裁切**；仅照片类素材走 `pic_cover()` 裁切铺满。`python-pptx` 按 sha1 复用包内已有 image part，因此复用原图不会产生重复媒体。

### 14 竞品分析① 技术路线格局

| 路线 | 代表厂商 | 关键参数 | 主要局限 |
|---|---|---|---|
| 热杀菌 UHT（行业主流） | 利乐 Tetra Pak、GEA、SPX FLOW | 加热至 135℃ 以上，杀灭全部微生物，可常温流通；需灭菌机 + 无菌灌装配套 | 梅纳反应改变风味与色泽；能耗高 |
| 超高压 HPP（高端冷杀菌） | Hiperbaric、JBT Avure | 5—20℃ 非热，最高 600 MPa，保压 1—3 分钟；全球装机 350 台以上 | 间歇在包处理难连续化；承压腔体投资高；包内滞留气体带来能效损失 |
| 超声非热（本项目路线） | Hielscher、Sonics & Materials 等 | 空化效应破坏微生物细胞结构；工业机型单机可达 16 kW，可多机并联 | 仅供通用超声处理单元，需自行串联萃取与灌装，缺少面向咖啡液的一体化整机 |

国内头部咖啡液品牌（如永璞浓缩咖啡液）在商品页即以 UHT 工艺作为卖点，可佐证 UHT 是当前主流路线。

### 15 竞品分析② 参数对标
7 行 × 5 列原生表格（可在 PowerPoint 内直接改），「本项目 SK-Ⅱ」列用红色边线标出：

| 对比维度 | 热杀菌 UHT | 超高压 HPP | 通用超声设备 | 本项目 SK-Ⅱ |
|---|---|---|---|---|
| 处理温度 | ＞135℃ | 5—20℃ | 近常温 | 56℃ |
| 作用机理 | 热致死 | 等静压 | 空化效应 | 空化 ＋ 低温协同 |
| 生产形态 | 连续管式 ＋ 无菌灌装 | 间歇 · 在包处理 | 通用处理单元 | 萃取—杀菌连续一体化 |
| 风味保留 | 低 · 梅纳反应改变风味色泽 | 高 | 高 | 高 · 第三方检测报告支撑 |
| 常温货架期 | 6—9 个月 | 较未处理延长 2—3 倍 | 需工艺验证 | 待中试验证 |
| 综合能耗 | 高 · 为发达国家 1.9 倍 | 高压泵功耗大 | 取决于配套工序 | 降低 20%~30% |

UHT 温度区间、6—9 个月保质期、1.9 倍能耗、56℃、20%~30% 节能均引自原稿第 10、16、17 页，未改动。「常温货架期」与「单位成本」标注为待中试验证，未给出未经验证的数字。
